# Changelog

All notable changes to `WP Fatal Error Handler` will be documented in this file.

## 0.2.0

- Require PHP 8.3 or later, and test against PHP 8.3 through 8.5.
- Mark as tested up to WordPress 7.1.
- Allow `symfony/var-dumper` 8.x.

## 0.1.3

- Disable the error handler when running tests.

## 0.1.2

- Fix styling of "hide" button.
- Add button to re-open Whoops after it was hidden.

## 0.1.1

- Fix for non-fatal errors not being ignored.

## 0.1.0

- Initial release
